# 智能记账 1:1 原生复刻「钱迹」极简纯粹风架构与设计规范

> 本文档规范了「智能记账」针对 **小米 15 Pro (HyperOS 2 / Android 15)** 的全面重构方案，1:1 原生复刻国内标杆软件「钱迹」的极简、纯粹、无广告、高信息密度质感，并重构为标准 C 端账号体系（账号/密码注册登录，单人单一账本）与高质感独立发布官网。

---

## 1. 设计语言与交互基调

1. **绝对克制与工业级质感**：
   - 彻底摒弃冗余的 AI 解释文案与花哨不实用的插画；
   - 采用 Android 原生 Material Design 3 轮廓与填充矢量图标体系；
   - 财务金额全量采用等宽数字排版（Tabular Figures），确保小数点与数字上下垂直对齐；
   - 浅色模式采用浅灰底（`#F6F7F9`），深色模式采用深空碳灰（`#121316`）。
2. **状态指示与色彩定义**：
   - 支出：沉稳黑色（深色下为浅白）或警示红（`#EF4444`）；
   - 收入：钱迹标志性翡翠绿（`#10B981` / `#059669`）；
   - 品牌主色：克制的专业群青蓝（`#2563EB`）；
   - 官方已对账标记：淡蓝微标（`#1D4ED8`）。

## 2. 客户端架构（经典 4-Tab 底部导航）

系统主界面分为四大独立模块，通过底部原生 NavigationBar 切换：

### 2.1 Tab 1：【明细】（流水明细看板）
- **顶部月度资产看板**：
  - 左上角：年月选择器（如 `2026年10月 ▾`），支持点击切换历史月份或翻月；
  - 核心数据三列规整展示：**本月支出**（粗体大字）、**本月收入**、**本月结余**（收入减支出的实时动态盈亏）；
  - 右上角：通知监听就绪指示绿点。
- **快捷操作区**：
  - `📋 粘贴账单`：一键读取系统剪贴板并解析入库；
  - `📁 导入文件`：支持从文件管理器选择 CSV 或 ZIP 压缩包；
  - `➕ 记一笔`：弹出原生极速记账全键盘。
- **按天时间线分组列表（Date-Grouped Timeline）**：
  - **日期行**：按倒序排列，头部显示如 `10月27日 星期二`，右侧展示当日小计 `支 25.80  收 0.00`；
  - **流水项**：
    - 左侧：圆形分类背景色与原生矢量分类图标；
    - 中间：第一行显示真实商家名称（如 `霸王茶姬`、`星巴克`、`老乡鸡`），第二行显示支付渠道与账户（如 `微信支付 · 建行信用卡(0001)`）；
    - 右侧：支出 `-¥25.80` / 收入 `+¥100.00`，如为官方账单核验记录显示蓝色角标 `已对账`；
    - 点击流水弹出底部详情操作弹窗（修改分类、调整金额、查看原始交易单号、删除）。

### 2.2 Tab 2：【图表】（多维专业统计报表）
- **时间维度切换**：顶部切换胶囊支持 `周`、`月`、`年`；
- **分类环形占比图（Donut Chart）**：
  - 原生 Compose Canvas 绘制平滑环形图，中心显示当期总支出与日均支出；
  - 点击对应分类扇区高亮放大，并联动下方排行；
- **分类消费排行榜**：
  - 按支出金额严格降序排列；
  - 每一项展示：排名序号（1, 2, 3...）、分类图标、分类名称、消费笔数、金额以及彩色占比进度条（如 `餐饮美食 45.2% ¥1,250.00`）；
- **每日支出走势柱状图（Bar Chart）**：
  - 呈现 1~31 日消费波动曲线，快速定位高频支出日与消费峰值。

### 2.3 Tab 3：【资产】（账户与资金流转）
- **顶部净资产总览**：总资产、总负债（信用卡待还与月付/白条）、净资产；
- **账户分组与联动**：
  - 网络支付：微信零钱、支付宝余额；
  - 银行储蓄卡：示例银行储蓄卡、招商银行等；
  - 信用/消费金融：示例银行信用卡、美团月付、京东白条；
- 记账时自动联动对应账户扣减或增加。

### 2.4 Tab 4：【我的】（标准个人中心）
- **顶部用户卡片**：
  - 未登录：显示默认头像与「点击登录 / 注册账号」；
  - 已登录：显示用户名/手机号、UID 与“云端密文已同步”；
- **单一账本原则**：有且仅有一本个人账本，去掉所有家庭/共享账本的复杂无用逻辑；
- **功能列表**：
  - ⚡ 自动记账服务（HyperOS 通知监听权限与保活引导）
  - 📥 官方对账单导入（剪贴板一键粘贴 / CSV / ZIP 自动解压）
  - ☁️ 云端备份与同步（支持立即备份、恢复与密码加密）
  - ℹ️ 关于智能记账与版本更新

## 3. 服务端与账号体系重构

彻底废除容易超时的验证码体系，回归成熟标准的 **账号/密码体系**：

1. **接口定义**：
   - `POST /api/auth/register`：输入 `username` / `phone` + `password`。服务端使用 PBKDF2-HMAC-SHA256 哈希密码，为用户自动初始化唯一专属个人账本。
   - `POST /api/auth/login`：输入 `username` / `phone` + `password`。验证通过后签发长期安全的 Bearer Token。
   - `GET /api/auth/me`：获取当前用户信息与账本信息。
   - `GET /api/sync/backup` 与 `PUT /api/sync/backup`：结合用户 Token 的零知识密文云端存取。
2. **端到端加密（E2EE）隐私保护**：
   - 账本明细在手机本地通过 AES-256-GCM 密文落盘；
   - 传给服务端的只有密文 Blob，云端与任何第三方均无法反查用户真实账单。

1. **视觉基调**：深空暗夜科技黑底色（`#090D16`）+ 极光呼吸微光（Emerald & Indigo Glow）；
2. **Hero 展区**：大标「智能记账 · 为小米 15 Pro 与 HyperOS 2 深度定制」，搭配高拟真手机界面原型 Mockup（展示 1:1 钱迹流水列表与环形图表）；
3. **Bento 核心功能特性网格**：
   - ⚡ 毫秒级闭环自动记账（支付宝、微信、美团外卖、京东、抖音）
   - 📊 钱迹级专业多维图表（环形占比、消费排行、走势柱状图）
   - 📥 全场景官方账单极速导入（剪贴板一键粘贴、微信 ZIP 自动解压）
   - 🔒 零知识端到端加密（本地密文落盘，多端安全备份）
4. **下载与发布日志卡片**：
   - 明确标注版本号（v1.1.0）、文件大小、SHA256、一键下载 APK 按钮；
