INSTALL

安装与设置

以小米 / HyperOS 为例，其他安卓手机路径类似；找不到时可在系统「设置」顶部搜索关键词。

  1. 下载并允许安装未知来源应用

    用系统浏览器点击上方下载按钮（微信内需先「在浏览器中打开」）。安装时若提示「禁止安装未知来源应用」，按提示允许当前浏览器安装；若被「纯净模式 / 安全守护」拦截，选择继续安装（可能需要验证小米账号）。

    设置 → 隐私保护 → 特殊权限设置 → 安装未知应用 → 浏览器 → 允许

  2. 开启通知使用权

    自动记账依赖读取微信、支付宝等 App 的支付通知，必须开启。首次打开 App 时按引导授权即可。

    设置 → 搜索「通知使用权」→ 智能记账 → 允许

  3. 开启无障碍辅助 可选

    仅用于识别微信 / 支付宝界面中的转账、发红包等不弹通知的支付。不开启也能正常使用通知自动记账。

    设置 → 更多设置 → 无障碍 → 已下载的应用 → 智能记账无障碍辅助 → 开启

  4. 允许自启动并关闭省电限制

    HyperOS 会清理后台，导致漏记。建议开启自启动、省电策略设为「无限制」，并在最近任务中下拉锁定智能记账。

    设置 → 应用设置 → 应用管理 → 智能记账 → 自启动：开启；省电策略：无限制

FAQ

常见问题

在微信里点下载没反应？

微信内置浏览器会拦截 APK 下载。请点右上角「···」，选择「在浏览器中打开」后再点击下载。

安装时提示「存在风险」或被拦截怎么办？

这是 HyperOS 对非应用商店安装包的通用提示。请确认安装包来自本页面，按提示选择继续安装；如开启了「纯净模式」，可能需要验证小米账号后放行。

可在下载按钮下方点击 SHA-256 复制校验值，与下载文件核对，确保安装包未被篡改。

为什么有时没有自动记上账？

常见原因：通知使用权未开启或被系统重置；App 被清理后台；对应支付 App 关闭了通知；或者该笔支付本身不弹通知（如微信转账、发红包）。

请检查 安装步骤 第 2、4 步，必要时开启第 3 步的无障碍辅助。漏掉的账目也可以用「记一笔」补录，或导入官方账单补齐。

导入官方账单会和自动记账重复吗？

不会重复入账。导入微信 / 支付宝官方账单（CSV、XLSX 或 ZIP）时会自动去重，只补充缺失的记录。

从旧版本升级，数据会丢吗？

直接下载新版安装包覆盖安装即可，无需先卸载。卸载 App 会清除本机数据，请避免先卸载再安装。

隐私：我的账目数据存在哪里？有广告吗？

本地优先：账目数据优先保存在你的手机上。App 不含广告。读取通知与无障碍权限仅用于识别支付信息并生成账目。

我的手机能用吗？

Android 8.0（API 26）及以上均可安装；针对小米 15 Pro、HyperOS 2 / Android 15 做了重点调优。其他品牌手机的后台管理设置路径会有所不同，可在系统设置中搜索「自启动」「电池优化」。
